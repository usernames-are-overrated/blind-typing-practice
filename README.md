# Blind Typing Practice

An interactive web application designed to help you master touch typing (blind typing) through adaptive practice sessions with intelligent difficulty adjustment and RSI prevention features.

## Features

### 🎯 Core Functionality
- **Interactive Typing Practice**: Real-time character-by-character feedback with visual indicators
- **Adaptive Difficulty**: Automatically adjusts challenge level based on your skill progression
- **Continuous Practice**: Practice for any duration - start and stop whenever you want
- **Performance Tracking**: Live WPM (Words Per Minute) and accuracy metrics

### ⌨️ Comprehensive Language Support
- **Natural Languages**: English, Spanish, French, German, Italian, Portuguese
- **Programming Languages**: JavaScript, Python, Java, C++, C#, Rust, Go, TypeScript, HTML, CSS
- **Keyboard Layouts**: QWERTY, Dvorak, Colemak, AZERTY, QWERTZ

### 🎮 Special Keys Practice
Practice essential special keys including:
- Control (Ctrl)
- Alt
- Shift
- Enter
- Tab
- Escape
- Backspace
- Delete

### 📊 Skill Progression System
- **Level Tracking**: Discreet skill level display that grows with your abilities
- **Intelligent Adaptation**: Difficulty increases as you improve
- **Celebration System**: Achievement notifications for level-ups and milestones
- **Persistent Progress**: All skill data saved locally in your browser

### 🎨 Customization
- **Color Themes**: Customize your color scheme with a dual-color picker

## Usage

### Getting Started

1. Open `index.html` in any modern web browser
2. Click "Start Practice" to begin
3. Type the displayed text without looking at your keyboard
4. Watch your skill level grow as you improve!

### Settings Configuration

Click the "Settings" button to customize:
- **Keyboard Layout**: Choose your physical keyboard layout
- **Language**: Select natural language or programming language
- **Special Keys**: Toggle special key practice on/off
- **Tips**: Show or hide typing tips
- **Breaks**: Enable/disable micro-breaks and set interval
- **Colors**: Customize your color scheme

### Practice Tips

1. **Home Row Position**: Keep your fingers on ASDF (left) and JKL; (right)
2. **Use the Bumps**: Feel for the raised bumps on F and J keys
3. **Don't Look Down**: Trust your muscle memory - resist peeking!
4. **Maintain Posture**: Sit straight with feet flat on the floor
5. **Light Touch**: Don't press keys too hard
6. **Regular Practice**: Short, frequent sessions beat long marathons

### Skill Progression

- Start at Level 0 with basic exercises
- Complete texts accurately to gain experience
- Level up to unlock more complex challenges
- Earn bonus points for special key mastery
- Celebrate milestones with achievement notifications
